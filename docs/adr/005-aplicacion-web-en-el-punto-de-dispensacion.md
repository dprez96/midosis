# ADR-005. Aplicación web en el punto de dispensación

**Estado:** aceptada

## Decisión

Aplicación web en el punto de dispensación

## Alternativas descartadas

- Aplicación de escritorio nativa

## Consecuencias

- **Ventaja.** Elimina instalador, actualizaciones y claves por terminal; traslada la firma al servidor
- **Desventaja.** Requiere conexión para emitir a aceptado y documentado
