# ADR-009. No integrarse con el sistema de la farmacia; reconocer el producto por lector de código de barras

**Estado:** aceptada

## Decisión

No integrarse con el sistema de la farmacia; reconocer el producto por lector de código de barras

## Alternativas descartadas

- Integración por API
- Captura del trabajo de impresión

## Consecuencias

- **Ventaja.** Ninguna implantación depende de un tercero
- **Ventaja.** Imposible que MiDosis afecte la dispensación
- **Desventaja.** Cuatro segundos adicionales por producto

---

Registrada en la sección 7 del informe de arquitectura.
