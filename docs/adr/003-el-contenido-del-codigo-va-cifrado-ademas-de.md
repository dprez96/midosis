# ADR-003. El contenido del código va cifrado, además de firmado

**Estado:** aceptada

## Decisión

El contenido del código va cifrado, además de firmado

## Alternativas descartadas

- Solo firmado, dado que no contiene identificadores

## Consecuencias

- **Ventaja.** Un lector genérico no obtiene información clínica
- **Desventaja.** Protección limitada: la clave está en la aplicación y el comprobante impreso es legible a se declara explícitamente el alcance
